## Outreach cadence

10 outreach → 4 calls → 2 paid pilots → 1 recurring subcontract in 90 days.

- Wave 1 in parallel: 5 named targets, warm LinkedIn intro, one-page capability note,
  ask = 20-minute call to scope ONE paid pilot deliverable (slice of a market map, or a
  technical screen on one live role).
- Wave 2 after a first reference case: pitch "white-collar technical layer inside your
  licence" + EOR route.
- Wave 3 after two case studies: vendor onboarding / associate-consultant applications.

## Harvesting technique (reusable)

For this class of list (firms + contacts + LinkedIn), run 8–12 `web_search` queries per
`execute_code` script via `from hermes_tools import web_search` and print ONLY
`url` + `description[:400]`, filtered in Python (e.g. keep only `linkedin.com/company`
URLs; drop aggregators: tracxn, leadiq, signalhire, rocketreach, apollo, zoominfo).
A direct `web_search` call with a large payload returns to the model as
`(N chars result)` — content unseen — so a harvest done that way produces citations
for data that was never actually read.
