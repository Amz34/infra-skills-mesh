# Phase 1 — BIM Literacy (Day 1-14)
Phone-first, koi software nahi chahiye. Har day = ek concept. Format: skill ka Lesson Format follow karo. Har lesson me FM/PM tie-in zaroori (medical gas, elevators, generators, LPG, healthcare/defense FM examples).

## Day 1 — BIM kya hai (✅ done manually 2026-09-08)
Building ka digital twin: geometry + data + relationships. Ek wall sirf line nahi — uski material, height, cost, fire-rating data hota hai. BIM = process (information management), software sirf tool. FM tie-in: as-built drawings vs live digital model jo maintenance records se juda ho.

## Day 2 — 2D CAD vs BIM
CAD = lines/drawing (drawing ko insaan padhta hai). BIM = objects with data (model ko software/insaan dono padhte hain). CAD me change = har drawing manually update; BIM me ek object change = har view/schedule khud update. Example: wall move karo → sections, quantities, cost sab sync. FM angle: BIM me ek valve ka data (manufacturer, install date, warranty) nikal sakte ho; CAD me sirf drawing.

## Day 3 — BIM Dimensions (3D se 7D tak)
3D = geometry. 4D = time/schedule (construction sequence animation). 5D = cost (quantities se estimates). 6D = sustainability/energy. 7D = FM/operations (asset data, warranties, maintenance). Aamir angle: 7D hi tere FM domain me hai — as-built model = digital asset register.

## Day 4 — LOD (Level of Development) 100→500
LOD 100 = conceptual (box). 200 = approximate geometry (generic). 300 = precise (specific size/materials — construction docs). 350 = coordination ready. 400 = fabrication. 500 = as-built (field verified). Real point: contract me LOD likha hota hai — delivery expectation control. Example: medical gas outlet LOD 300 = exact position/spec; LOD 500 = installed reality ke hisaab se.

## Day 5 — IFC (open format)
IFC = BIM ka universal language (ISO 16739), vendor-lock se bachata hai. Revit/Navisworks/Solibri sab IFC bol sakte hain. Koi software company kabhi band ho jaye to data tera rehta hai. FM angle: handover me IFC + COBie maangna = smart client move.

## Day 6 — ISO 19650 + CDE (Common Data Environment)
ISO 19650 = BIM information management ka global standard (UK BS 1192 ki evolution). CDE = ek shared source of truth (cloud platform jaise Autodesk ACC/BIM360) — workflow: Work in Progress → Shared → Published → Archive. Aamir angle: CDE = project ka single source of truth — confusion/duplicate drawings khatam.

## Day 7 — COBie + FM Handover
COBie = structured spreadsheet format for asset data handover (room/equipment/warranty/spares). FM ko operation ke liye chahiye: kya install hai, kab service, warranty kab khatam. Tie-in: teri FM duniya — medical gas system ka full asset register model se auto-extract.

## Day 8 — Clash Detection & Coordination
Models overlay karke collisions pakadna (duct vs beam vs pipe vs gas line). Navisworks jaise tools me 3D me clash = red sphere highlight. 2D drawings me yeh clashes tab pata chalta hai jab site pe ho. Aamir angle: MEP coordination tera domain — medical gas line vs HVAC duct clash construction se pehle pakadna = lakhs ki bachat.

## Day 9 — Model Lifecycle (design → construction → handover)
Design model (LOD 300) → construction me 4D/5D (schedule/cost) → as-built (LOD 500) → FM me 7D. Har phase me model ka "use" badalta hai. PM angle: har phase ka deliverable contract me define karo.

## Day 10 — BIM Roles
BIM Manager (standards/process/contracts), BIM Coordinator (clash detection, model QA), BIM Modeler (model banata hai), Information Manager (ISO 19650 pe). PM ka role: EIR (Employer's Information Requirements) + BEP (BIM Execution Plan) approve karna, quality gate check karna. Saudi me BIM Manager roles ki demand badh rahi hai.

## Day 11 — Tool Landscape
Authoring: Revit (architecture/structure/MEP), ArchiCAD. Review/coordination: Navisworks, Solibri. CDE: Autodesk Construction Cloud (ACC), BIM360. Viewers (free): Autodesk Viewer, BIMvision. AI layer (naya trend): MCP+Claude agents jo model ko edit karte hain (atomatiq pattern). Rule: tool nahi, workflow seekho.

## Day 12 — Saudi/GCC BIM Mandates + Market
Saudi: giga-projects (NEOM, Qiddiya, Red Sea) BIM mandatory hai practically; Saudi BIM standards evolve ho rahe hain (2024-25 me BIM adoption push); Dubai me 2014 se govt buildings BIM mandatory (DXB municipality). International: UK 2016 se public projects BIM Level 2 mandatory. Aamir angle: SCE + BIM literacy = Saudi market me strong positioning.

## Day 13 — BIM Contracts: EIR & BEP
EIR = client ka kya chahiye (client-side document — employer kehta hai). BEP = consultant/contractor kaise dega (supply-side response). Dono me: LOD, disciplines, CDE platform, clash process, handover format (IFC/COBie). PM ka kaam: dono documents ko samajhna + enforce karna. Chhota cheat: EIR = kya, BEP = kaise.
