# Phase 2 — Revit Lab (Windows Laptop Sessions)
Revit = Windows-only. Official Autodesk 30-day trial ya education license (login user khud karega — OTP/2FA steps user side). Free practice: trial me sample project (rac_basic_sample_project.rvt) milta hai. Har session ~30-45 min. User ka coding background nahi hai — UI steps exact do.

## Lab 0 — Install Setup
Autodesk official site → Revit trial download (~5GB) → Autodesk account login (user side OTP) → install (default options) → open. Phir: open sample file `rac_basic_sample_project` (Home screen → Models → sample). Verify: project browser left side dikhe.

## Lab 1 — UI Tour (10 min rule)
Elements: Ribbon (top tabs: Architecture, Structure, Systems, Insert...), Project Browser (left — views ka tree), Properties Palette (right — selected object ka data), Viewport (beech). Action: ribbon ke har tab pe click karke 1 min dekho, kya kya hai note karo (mat samjho, bas dekho). Property window me ek wall select karke data dekho.

## Lab 2 — Levels & Grids
Levels = floors (vertical datums, section/elevation me dikhte hain). Grids = column lines (plan me). Action: South elevation view kholo, Level 2 select karke +20' move karo (ya naya Level add karo), dekho plan views automatically update. Insight: Revit me "drawing" nahi — model me change, views reflect karta hai (Day 2 concept live!).

## Lab 3 — Walls & Properties
Architecture tab → Wall → click-drag ek wall banao. Properties me: height, thickness, material. Action: ek 30 ft wall banao, phir properties me height badlo, 3D view (cube icon) me dekho. Ek door (Door tool) wall me lagao. Wall select karke "Edit Type" kholo — type vs instance parameters ka concept yahin se aata hai (Phase 3 ke liye base).

## Lab 4 — Views & Visibility
Project Browser me: Floor Plans / Ceiling Plans / Elevations / Sections / 3D. Action: Section tool se ek section banao (property me "Section" milta hai). Visibility/Graphics (shortcut VG) kholo — categories on/off (furniture hide karo). Insight: views model ko dekhne ke alag tareeke hain, alag drawings nahi.

## Lab 5 — Schedules & Quantities
View tab → Schedules → Schedule/Quantities → Categories (Doors) → fields (type, width, height, count). Action: Door schedule banao → phir model me ek door delete karo → schedule khud update hua? Yahi BIM ka magic hai (Day 2 review). FM angle: yehi schedule COBie/asset register ka embryo hai.

## Lab 6 — Sheets & Titleblocks
Sheets = drawing sheets (plot ready). View tab → Sheet. Action: ek naya sheet banao (titleblock select), phir floor plan ko drag karke sheet pe rakho (viewport), scale set karo. Print/export PDF kar ke dekho. Insight: har drawing sheet model ka "window" hai — alag se kuch nahi banaya.

## Lab 7 — Families Intro (concept day)
Family = object ka template/class (door, chair, pump). Type = family ki variant (900mm door vs 1000mm). Load Family = library se object model me lana. Action: Architecture → Component → Load Family → US Metric library me browse karo, koi furniture load karke place karo. Bas concept — detailed family creation Phase 3 me.

## Lab 8 — Navigation Mastery
Mouse: middle-button = pan, shift+middle = orbit, scroll = zoom. Keyboard: ZX = undo/redo (undo ko ZX bolte hain Revit me!), VG = visibility, WW = fit view. Action: sample model me pan/orbit/zoom practice 10 min; 3D view me fly mode try karo (shift+wheel click + WASD). Speed = in tools ka muscle memory.

## Lab 9 — Model Reading Exercise (PM drill)
Sample project kholo, yeh questions answer karo (main test karunga): kitne levels hain? konse rooms? total doors count (schedule se)? koi ek room ka area? building ka total height? PM real task: model se answer nikalna — yahi model reading hai.

## Lab 10 — Discipline Peek: MEP Systems (concept)
Systems tab kholo (Electrical/Mechanical/Piping panels). MEP sample project (rac me nahi, rme_basic_sample_project.rvt alag trial me milta hai). Bas concept: circuits/systems connections hoti hain — equipment se panel tak. Atomatiq post ka "33 circuits" yahin se aata hai — AI ne circuits banaye, par circuits ka concept samajhna tera kaam. Detail Phase 3 me.

## Lab 11 — Clash Thinking (Navisworks optional)
Autodesk viewer me 2 models overlay concept. Optional: Navisworks freedom (free viewer) install karke clash review dekhna. Agar time na ho to concept-based hi raho. PM drill: clash report padhna seekhna (agla step — client ko report samjhana).

## Lab 12 — Phase 2 Wrap + Mini Project
Chhota mini-project: 1 room ka layout banao (levels, 4 walls, 1 door, 1 window, furniture, schedule, ek sheet) — sab labs ka combination. Done = Revit fundamentals complete. Phase 3 ke liye ready.
